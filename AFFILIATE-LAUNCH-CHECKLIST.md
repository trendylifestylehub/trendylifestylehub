# Trendy Lifestyle Hub — Affiliate Website Launch Checklist

## Before publishing products
- [ ] Join the retailer/affiliate programme and read its rules.
- [ ] Use the exact approved tracking URL for each product.
- [ ] Confirm product name, category, image rights, product details and retailer.
- [ ] Add a verified HTTPS affiliate URL. A product cannot be published without it.
- [ ] Add a price only after checking it; enter the date it was checked.
- [ ] Do not add invented ratings, reviews, discounts, stock or claims.
- [ ] Write original useful descriptions and editorial notes; do not copy retailer text wholesale.
- [ ] Add descriptive image alt text.
- [ ] Preview each product on mobile and test its retailer redirect.

## Trust, policy and content
- [ ] Keep Affiliate Disclosure visible near affiliate recommendations and in the footer.
- [ ] Review About, Contact, Privacy, Cookie, Terms and Editorial Policy pages; replace generic text with your actual business/contact and data practices.
- [ ] Publish useful original buying guides and articles before applying for advertising.
- [ ] Do not claim personal testing unless you actually tested the product.
- [ ] Make contact messages and newsletter consent records accessible only to the admin.

## Technical checks
- [ ] Test the separate Cloudflare deployment before changing the main website.
- [ ] Verify admin login, logout and unauthorized API rejection.
- [ ] Test product create/edit/draft/publish/delete.
- [ ] Test category, page and blog create/edit.
- [ ] Test R2 uploads with real image files and reject oversized/non-image files.
- [ ] Test AI only after binding Workers AI. Review all generated text.
- [ ] Test analytics only after consent; confirm rejection sends no analytics events.
- [ ] Keep AdSense disabled until approved. Configure a Google-certified CMP where required (including EEA/UK/Switzerland).
- [ ] Check robots.txt, sitemap.xml, canonical URLs, 404 page, mobile layout, keyboard navigation and page speed.
- [ ] Back up D1 and keep a copy of the old website before switching domains.

## Important remaining integrations
Newsletter delivery, automated contact email notifications, advanced conversion analytics, rich-text editing, media library browsing, full consent-management platform integration, and formal security/accessibility reviews are not included in this starter release.
